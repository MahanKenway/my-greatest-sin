# مسیر تأییدشدهٔ اجرای مرحله‌ای FlyWire v783

## تأیید استفاده

کاربر در ۲۲ اوت ۲۰۲۶ تأیید کرد که پروژه را در مسیر **غیرتجاری** پیش می‌برد و مسئولیت رعایت شرایط داده و citation را پذیرفته است. این تأیید برای دریافت و پردازش محلیِ فایل‌های رسمی v783 به‌کار می‌رود؛ این سند مجوز تازه‌ای ایجاد نمی‌کند و انتشار عمومی داده نیازمند گیت جداگانه است.

## قواعد غیرقابل‌تغییر

| حوزه | قاعده |
|---|---|
| منبع | فقط رکورد رسمی FlyWire در Zenodo؛ نه GitHub mirror و نه دادهٔ clone‌شده از مخزن ثالث. |
| مجوز داده | `CC BY-NC 4.0` با attribution و citation رسمی. |
| کد | کد مخزن‌های ثالث ممکن است MIT باشد، اما این مجوز به دادهٔ FlyWire تعمیم داده نمی‌شود. |
| محل داده | خارج از درخت git و خارج از بسته‌های عمومی پروژه تا گیت انتشارِ جداگانه. |
| اجرا | ابتدا manifest، SHA-256، حافظه و سازگاری WebGPU؛ اجرای کامل CPU ممنوع است. |
| ادعا | توپولوژی منبع از حسگرها، نگاشت وزن، decoder موتور، بدن و رفتارِ مدل‌شده جدا برچسب می‌خورد. |

## مسیر دادهٔ رسمی

بستهٔ staged با `proofread_root_ids_783.npy` و `proofread_connections_783.feather` ساخته می‌شود. تبدیل‌کنندهٔ پروژه جریان Feather را به chunkهای CSR، manifest دارای transform provenance و SHA-256 تبدیل می‌کند. فایل خروجی فقط پس از کنترل کامل checksum قابل‌بارگذاری در cache محلی است.

## ممیزی دریافت مستقیم

در ۲۲ اوت ۲۰۲۶، دو فایل مستقیماً از endpoint رسمی Zenodo دریافت و خارج از درخت پروژه نگه‌داری شدند:

| فایل | اندازهٔ ثبت‌شده | SHA-256 دریافت‌شده |
|---|---:|---|
| `proofread_root_ids_783.npy` | ۱٬۱۱۴٬۱۶۸ بایت | `7c7b7e818e9232e5ab64793d52ba20574dbe9da3a6509fbc74193b0f259a01be` |
| `proofread_connections_783.feather` | ۸۵۲٬۰۲۲٬۲۷۴ بایت | `24f960ae3e7d4f8cd30db3b62e99fb5179cc3d1e76d8c155bfb441e9737d3faf` |

اندازهٔ فایل‌ها با پاسخ API رکورد Zenodo منطبق است. این هش‌ها provenance دریافت را ثبت می‌کنند؛ manifest حاصل از تبدیل نیز برای هر chunk هش مستقل خواهد داشت.

> حدود ۱۴۰ هزار نورون و بیش از ۱۵ میلیون یال، به backend تنک WebGPU و benchmark واقعی دستگاه نیاز دارند. نبودِ سازگاری به معنی نمایش وضعیت staged است، نه جایگزینی پنهان با دادهٔ کوچک‌تر یا ادعای اجرای کامل.

## نتیجهٔ تبدیل staged

تبدیل‌کنندهٔ streaming روی دو فایل رسمی اجرا شد و یک بستهٔ خارجیِ DFLY تولید کرد. بسته در مسیر خارج از مخزن نگه‌داری می‌شود و هیچ‌یک از فایل‌های آن به git، Space، Dataset یا Zenodo این پروژه اضافه نشده‌اند.

| ویژگی | نتیجهٔ اعتبارسنجی |
|---|---:|
| نورون‌های proofread | ۱۳۹٬۲۵۵ |
| یال‌های پذیرفته‌شده | ۱۶٬۸۴۷٬۹۹۷ |
| chunkهای checksummed | ۱۲ |
| ستون‌های منبع | `root_id`، `incoming_offsets`، `source_index`، `synapse_count`، `neuropil_index`، `nt_probabilities` |
| اندازهٔ بستهٔ DFLY | ۳۵۶ MiB |
| کنترل checksum chunk | همهٔ ۱۲ chunk با manifest منطبق هستند |

CSR پایهٔ این بسته حدود **۱۶۱٫۲۰ MiB** و کمینهٔ آرایه‌های runtime حدود **۱۸۰٫۴۶ MiB** است؛ این ارقام cache مرورگر، بافرهای موقت GPU و visualization را شامل نمی‌شوند. اجرای ۲۰۰ گام در ثانیه روی CPU حدود **۳٬۳۶۹٬۵۹۹٬۴۰۰** بازدید یال در ثانیه می‌طلبد و صریحاً خارج از محدودهٔ backend CPU فعلی است.

## بررسی capability مرورگر

پیش‌نمایش Chromium این محیط در ۲۲ اوت ۲۰۲۶ `navigator.gpu` یا adapter در دسترس نداشت. بنابراین حالت FlyWire در این محیط به‌درستی `WEBGPU_UNAVAILABLE` است و هیچ benchmark یا اجرای GPU انجام نشد. این نتیجه به مرورگر یا دستگاه نهایی کاربر تعمیم داده نمی‌شود؛ آن محیط باید adapter، محدودیت buffer و kernel تنک را جداگانه benchmark کند.
