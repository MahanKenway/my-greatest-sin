# اعتبارسنجی باغ سه‌بعدی

## دارایی‌ها و مرز معنا

باغ با انتخابی کوچک از **۱۷ مدل GLB** از Kenney Nature Kit و مجوز CC0 ساخته شد: سه درخت، بوته و دو نوع علف، سنگ‌ها، نیلوفر، قارچ، کنده، سه نوع گل، دو قطعه مسیر سنگی و پل چوبی. یک آبشار کوچکِ رویه‌ای، بسترهای خزه‌ای، فانوس‌ها و نورهای کرم‌شب‌تاب نیز افزوده شده‌اند. این دارایی‌ها فقط به‌صورت `MODELLED MAPPING` در حاشیهٔ محیط مشاهده قرار می‌گیرند و هیچ تأثیری بر حسگرها، بدن‌ها، اتصال‌نگار یا پویایی عصبی ندارند.

مدل مگس اکنون یک GLB کاملِ ارائه‌ای بر پایهٔ مش‌های Apache-2.0 NeuroMechFly است. مدل C. elegans نیز یک GLB ارائه‌ایِ فشرده و مستقل با ارجاع بصری به OpenWorm MIT است. هر دو مدل به ریشهٔ حرکتی موجود متصل‌اند؛ بنابراین حرکت بدن همچنان یک نگاشت موتور مدل‌شده است، نه ادعای مورفولوژی منبع یا اجرای اتصال‌نگار.

## شواهد اجرای مرورگر

یک رندر تازهٔ مرورگر، بدن GLB کامل مگس، پل، آبشار و اثرهای نمایشی باغ را بدون خطای console نمایش داد. سپس انتخاب `C. ELEGANS` انجام شد و باغ مشترک باقی ماند؛ هم‌زمان بستهٔ منبع کرم با `279 N / 6261 E` و `SOURCE PACK ACTIVE` فعال شد. تأیید تازهٔ کنسول مرورگر هیچ خطای runtime نداشت. این آزمون تضمین می‌کند که لایهٔ تزئینی باغ و مدل‌های ارائه‌ای با سوییچ گونه یا مسیر اجرای دادهٔ منبع تداخل ندارند.

> ابزار screenshot تمام‌صفحه به‌طور شناخته‌شده HUD ثابت و canvas را پنهان می‌کند و ممکن است فقط میدان تیرهٔ پس‌زمینه را ثبت کند. برای این پروژه، screenshot نمای viewport و بررسی مستقیم DOM/console مرورگر مبنای معتبرترِ تأیید ترکیب‌بندی است.

## کنترل‌های تکمیل‌شده

| کنترل | نتیجه |
|---|---|
| TypeScript | `pnpm check` موفق |
| آزمون‌ها | ۷ فایل و ۱۴ آزمون موفق |
| ساخت تولید | موفق پس از آزادسازی watcherهای اضافی TypeScript |
| رندر FlyWire staged | بدون خطای console؛ `0 N / 0 E` حفظ شد |
| رندر C. elegans | بدون خطای console؛ `279 N / 6261 E` و `SOURCE PACK ACTIVE` حفظ شد |
| مدل‌های بدن | GLB کامل Drosophila و C. elegans به ریشه‌های موتور مدل‌شده متصل شدند |
| پویانمایی محیط | نوسان آهستهٔ علف‌ها، حرکت کرم‌شب‌تاب‌ها و جریان ظاهری آبشار جدا از runtime علمی اجرا می‌شود |
