Privacy Policy

Last updated: 29 September 2026. My Greatest Sin is a browser-based scientific visualization and observation bench maintained by Mahan Tavakoli.

Analytics and public requests

Production builds may load the configured Umami analytics endpoint when deployment environment variables provide one. That service can receive privacy-preserving visit and event metrics according to its configuration and policy. The site does not use advertising identifiers or sell personal information. The browser also requests public scientific manifests, maps, and runtime assets from configured upstream hosts; those hosts may retain ordinary technical request logs under their own policies.

Local browser data

Theme choice and interface state may be stored in local storage. Some interface components can use a short-lived cookie for a UI preference. These values remain on the device until cleared and are not an account profile.

Scientific data and uploads

The application reads public or explicitly configured scientific data needed for the visualization and keeps bounded summaries in the browser runtime. It is not a medical device and does not request health data. Do not provide personal, confidential, or regulated data through the interface.

Retention and choices

There is no first-party user account database in the static browser experience. Clear site data, block analytics, or use private browsing to remove local preferences. Analytics and upstream hosts control their own retention; consult their policies for access or deletion requests.
